
`adb shell` 是连接到 Android 设备的命令行接口。这对面试和实际开发都很重要。

## **基础连接命令**

```bash
# 列出连接的设备
adb devices

# 连接到设备
adb shell                    # 进入设备 shell
adb shell <command>          # 执行单条命令

# 指定设备（多设备情况）
adb -s <device_id> shell

# 连接网络设备
adb connect <device_ip:5555>
```

## **应用层命令**

### 包管理（PM）

```bash
# 列出所有已安装应用
adb shell pm list packages
adb shell pm list packages -3          # 仅第三方应用
adb shell pm list packages -s          # 系统应用

# 获取应用信息
adb shell pm dump <package_name>       # 完整应用信息
adb shell pm path <package_name>       # 应用 APK 路径

# 安装/卸载
adb shell pm install-multiple <apk1> <apk2>
adb shell pm uninstall <package_name>
adb shell pm clear <package_name>      # 清空数据

# 获取 UID（重要用于权限分析）
adb shell pm get-app-links <package_name>
```

### 活动管理（AM）

```bash
# 启动应用
adb shell am start -n <package>/<activity>
adb shell am start -n com.example.app/.MainActivity

# 启动带参数
adb shell am start -a android.intent.action.VIEW \
  -d "https://example.com"

# 停止应用
adb shell am force-stop <package_name>

# 获取当前活动
adb shell dumpsys window | grep "mCurrentFocus"

# 监听应用崩溃
adb shell logcat *:S AndroidRuntime:E
```

## **系统命令**

### 文件系统

```bash
# 基础 Linux 命令
adb shell ls -la /data/app/              # 应用数据目录
adb shell pwd                             # 当前目录
adb shell cat /system/build.prop         # 系统属性

# 数据库访问
adb shell sqlite3 /data/data/<package>/databases/<db_name>

# 文件操作
adb shell cp <source> <dest>
adb shell rm <file>
adb shell mkdir -p <path>
```

### 系统属性（getprop/setprop）

```bash
# 查看系统属性
adb shell getprop                        # 所有属性
adb shell getprop ro.build.version.sdk   # Android API 级别
adb shell getprop ro.product.model       # 设备型号
adb shell getprop ro.debuggable          # 是否可调试

# 设置属性（需要 root）
adb shell setprop sys.usb.config adb
adb shell setprop ro.debuggable 1
```

## **日志和调试**

### Logcat

```bash
# 实时日志
adb logcat

# 过滤日志
adb logcat | grep <keyword>
adb logcat *:S <tag>:D                  # 只显示指定标签的 DEBUG 及以上

# 应用专属日志
adb logcat --pid=$(adb shell pidof <package_name>)

# 保存日志到文件
adb logcat > logcat.txt
adb logcat -c                           # 清空日志缓冲
```

### Dumpsys（系统转储）

```bash
# 活动栈
adb shell dumpsys activity              # 完整活动信息
adb shell dumpsys activity activities   # 仅活动栈

# 内存信息
adb shell dumpsys meminfo <package_name>    # 应用内存
adb shell dumpsys meminfo | grep TOTAL      # 总内存

# 数据库连接
adb shell dumpsys dbinfo <package_name>

# 电池状态
adb shell dumpsys battery

# 网络信息
adb shell dumpsys connectivity
```

## **性能分析**

### CPU/内存

```bash
# top 命令（实时资源使用）
adb shell top -n 1                      # 显示一次后退出
adb shell top -b -n 10 -d 1              # batch 模式，10 次，间隔 1 秒

# ps 命令（进程列表）
adb shell ps -A                         # 所有进程
adb shell ps -p <pid>                  # 特定进程

# 获取应用进程 ID
adb shell pidof <package_name>
```

### ANR/Crash 分析

```bash
# 查看 ANR 日志
adb shell cat /data/anr/traces.txt

# 获取 native crash (tombstones)
adb shell ls -la /data/tombstones/
adb shell cat /data/tombstones/<crash_file>
```

### Systrace/Perfetto

```bash
# 获取 Systrace
adb shell atrace -b 32000 --async_start sched gfx view wm

# 停止并生成报告
adb shell atrace --async_stop > trace.html
```

## **文件传输**

```bash
# 推送文件到设备
adb push <local_file> <device_path>
adb push app-debug.apk /data/local/tmp/

# 拉取文件到本地
adb pull <device_path> <local_path>
adb pull /data/app/com.example/.apk ./

# 拉取数据库
adb pull /data/data/<package>/databases/<db_name> ./
```

## **网络和连接**

```bash
# IP 地址
adb shell ifconfig
adb shell ip addr show

# DNS
adb shell cat /etc/resolv.conf

# 网络测试
adb shell ping 8.8.8.8
adb shell netstat -an

# 代理设置
adb shell settings put global http_proxy <proxy_address>:<port>
adb shell settings delete global http_proxy
```

## **权限相关**

```bash
# 查看应用权限
adb shell pm dump <package_name> | grep permission

# 授予运行时权限
adb shell pm grant <package_name> <permission>
adb shell pm grant com.example.app android.permission.CAMERA

# 撤销权限
adb shell pm revoke <package_name> <permission>

# 检查权限
adb shell dumpsys package <package_name> | grep android.permission
```

## **逆向工程相关**

```bash
# 提取 APK
adb pull /data/app/<app_folder>/base.apk
adb pull /data/app/com.example.app*/

# 获取签名信息
adb shell pm dump <package_name> | grep "signatures"

# 查看 Dex 文件
adb shell ls -la /data/app/<package>/

# 获取应用源信息
adb shell dumpsys package <package_name> | grep -E "codePath|resourcePath"
```

## **面试常考命令组合**

### 场景 1：调查内存泄漏

```bash
# 1. 获取应用进程 ID
adb shell pidof com.example.app

# 2. 查看内存
adb shell dumpsys meminfo 12345

# 3. 导出堆（配合 LeakCanary 或 Android Profiler）
adb shell am dumpheap <pid> /data/local/tmp/heap.hprof
adb pull /data/local/tmp/heap.hprof
```

### 场景 2：分析 ANR

```bash
adb logcat | grep "ANR in"
adb shell cat /data/anr/traces.txt | head -100
```

### 场景 3：获取系统信息

```bash
adb shell getprop | grep -E "ro.build|ro.product"
adb shell dumpsys activity | grep "mInputMethodManager"
```

## **需要 Root 的高级命令**

```bash
# 重新挂载系统分区（可写）
adb shell mount -o rw,remount /system

# 修改系统文件
adb shell cp /data/local/tmp/build.prop /system/build.prop

# 查看 SELinux 状态
adb shell getenforce
adb shell setenforce 0              # 禁用 SELinux（需 root）
```
