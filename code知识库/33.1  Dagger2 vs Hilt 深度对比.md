```
Hilt = Dagger2 + Android特定封装
```

**Hilt 是建立在 Dagger2 基础之上的高层封装框架**，由 Google 官方开发（2020年发布），目的是**简化 Dagger2 在 Android 开发中的使用**。

---

## 发展历程

```
Dagger (2011) ← 独立项目
    ↓
Dagger2 (2014) ← Google接手，重写，编译期生成
    ↓
Hilt (2020) ← Google官方Android DI标准方案
```

**官方建议**: 新项目使用 **Hilt**，维护旧项目才用 Dagger2。

## 核心区别对比表

|维度|Dagger2|Hilt|
|---|---|---|
|**学习曲线**|陡峭 🔴|平缓 🟢|
|**代码量**|多|少（少30-50%）|
|**Component管理**|手动创建|自动生成|
|**Scope支持**|需自定义|预定义好|

|**Activity/Fragment**|手动inject|自动inject|

## 详细对比

### 1️⃣ **Scope 生命周期管理**

#### Dagger2（需自定义）

```kotlin
// 自己定义Scope注解
@Scope
@Retention(AnnotationRetention.RUNTIME)
annotation class ActivityScope

@Scope
@Retention(AnnotationRetention.RUNTIME)
annotation class FragmentScope

// 使用时麻烦
@ActivityScope
@Component
interface ActivityComponent
```

#### Hilt（预定义好的）

```kotlin
// Hilt已预定义，开箱即用
@HiltViewModel               // ViewModel作用域
@ActivityScoped              // Activity生命周期
@FragmentScoped              // Fragment生命周期
@Singleton                   // App生命周期
@ServiceScoped               // Service生命周期
```

---

### 2️⃣ **Component 创建**

#### Dagger2（手动创建）

```kotlin
// ❌ 需要手动创建多个Component
@Singleton
@Component(modules = [AppModule::class])
interface AppComponent {
    fun inject(mainActivity: MainActivity)
    fun inject(detailActivity: DetailActivity)
}

@ActivityScope
@Subcomponent(modules = [ActivityModule::class])
interface ActivityComponent {
    fun inject(fragment: HomeFragment)
}

// Application中手动初始化
class MyApp : Application() {
    companion object {
        lateinit var appComponent: AppComponent
    }
    
    override fun onCreate() {
        super.onCreate()
        appComponent = DaggerAppComponent.create()
    }
}

// Activity中手动初始化子Component
class MainActivity : AppCompatActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        val activityComponent = DaggerActivityComponent.builder()
            .bind(this)
            .build()
        activityComponent.inject(this)
    }
}
```

#### Hilt（自动生成）

```kotlin
// ✅ 一个注解搞定
@HiltAndroidApp  // 自动创建ApplicationComponent
class MyApp : Application()

// 在需要注入的地方添加@AndroidEntryPoint
@AndroidEntryPoint
class MainActivity : AppCompatActivity()

@AndroidEntryPoint
class HomeFragment : Fragment()

// 就这样，Hilt自动管理所有Component的生命周期
```

---

### 3️⃣ **ViewModel 注入**

#### Dagger2（复杂）

```kotlin
// 需要自定义Factory
class UserViewModelFactory @Inject constructor(
    private val repository: UserRepository
) : ViewModelProvider.Factory {
    @Suppress("UNCHECKED_CAST")
    override fun <T : ViewModel> create(modelClass: Class<T>): T {
        return UserViewModel(repository) as T
    }
}

// 在Activity中使用
class MainActivity : AppCompatActivity() {
    @Inject
    lateinit var viewModelFactory: UserViewModelFactory
    
    private val viewModel: UserViewModel by viewModels { viewModelFactory }
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        MyApp.appComponent.inject(this)  // 先inject factory
    }
}
```

#### Hilt（简单）

```kotlin
// 直接在ViewModel添加@HiltViewModel
@HiltViewModel
class UserViewModel @Inject constructor(
    private val repository: UserRepository,
    savedStateHandle: SavedStateHandle  // 自动处理
) : ViewModel()

// Activity中直接使用，零代码
@AndroidEntryPoint
class MainActivity : AppCompatActivity() {
    private val viewModel: UserViewModel by viewModels()  // 完成！
}
```

---

### 4️⃣ **Module 定义**

#### Dagger2

```kotlin
@Module
class DataModule {
    @Provides
    @Singleton
    fun provideApiService(
        okHttpClient: OkHttpClient
    ): ApiService {
        return Retrofit.Builder()
            .client(okHttpClient)
            .baseUrl(API_BASE_URL)
            .build()
            .create(ApiService::class.java)
    }
}

// Component需要显式关联Module
@Singleton
@Component(modules = [DataModule::class])
interface AppComponent
```

#### Hilt

```kotlin
// 需要指定Qualifier和安装位置
@Module
@InstallIn(SingletonComponent::class)  // 指定作用域
class DataModule {
    @Provides
    @Singleton
    fun provideApiService(okHttpClient: OkHttpClient): ApiService {
        return Retrofit.Builder()
            .client(okHttpClient)
            .baseUrl(API_BASE_URL)
            .build()
            .create(ApiService::class.java)
    }
}

// 不需要创建Component，Hilt自动处理
```

---

### 5️⃣ **注入目标支持**

#### Dagger2

```kotlin
// 仅支持手动创建的类
class MainActivity : AppCompatActivity() {
    @Inject
    lateinit var repository: UserRepository
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        MyApp.appComponent.inject(this)  // 手动inject
    }
}

// ❌ 不支持直接在Fragment/Service注入
```

#### Hilt

```kotlin
// ✅ 支持所有Android组件
@AndroidEntryPoint
class MainActivity : AppCompatActivity() {
    @Inject lateinit var repository: UserRepository  // 自动inject
}

@AndroidEntryPoint
class HomeFragment : Fragment() {
    @Inject lateinit var repository: UserRepository  // 自动inject
}

@AndroidEntryPoint
class MyService : Service() {
    @Inject lateinit var repository: UserRepository  // 自动inject
}

// 甚至支持BroadcastReceiver
@AndroidEntryPoint
class MyReceiver : BroadcastReceiver()
```

## 完整示例对比

### 场景：构建用户模块

#### ❌ Dagger2 完整实现

```kotlin
// 1. 定义Module
@Module
class UserModule {
    @Provides
    @Singleton
    fun provideApiService(): UserApiService {
        return UserApiService()
    }
    
    @Provides
    @Singleton
    fun provideRepository(api: UserApiService): UserRepository {
        return UserRepository(api)
    }
}

@Module
class UserViewModelModule {
    @Provides
    fun provideUserViewModel(repository: UserRepository): UserViewModel {
        return UserViewModel(repository)
    }
}

// 2. 定义Scope
@Scope
@Retention(AnnotationRetention.RUNTIME)
annotation class ActivityScope

// 3. 定义AppComponent和子Component
@Singleton
@Component(modules = [UserModule::class, UserViewModelModule::class])
interface AppComponent {
    fun userActivityComponent(): UserActivityComponent
}

@ActivityScope
@Subcomponent(modules = [UserModule::class])
interface UserActivityComponent {
    fun inject(activity: UserActivity)
    fun inject(fragment: UserFragment)
}

interface UserActivityComponentBuilder {
    fun build(): UserActivityComponent
}

// 4. 在Application中初始化
class MyApp : Application() {
    companion object {
        lateinit var appComponent: AppComponent
    }
    
    override fun onCreate() {
        super.onCreate()
        appComponent = DaggerAppComponent.create()
    }
}

// 5. 在Activity中注入
class UserActivity : AppCompatActivity() {
    @Inject
    lateinit var viewModel: UserViewModel
    
    @Inject
    lateinit var repository: UserRepository
    
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        MyApp.appComponent.userActivityComponent().inject(this)
    }
}

// 行数：大约100行
```

#### ✅ Hilt 完整实现

```kotlin
// 1. 定义Module（简化）
@Module
@InstallIn(SingletonComponent::class)
class UserModule {
    @Provides
    @Singleton
    fun provideApiService(): UserApiService = UserApiService()
    
    @Provides
    @Singleton
    fun provideRepository(api: UserApiService): UserRepository = UserRepository(api)
}

// 2. 定义ViewModel
@HiltViewModel
class UserViewModel @Inject constructor(
    private val repository: UserRepository
) : ViewModel()

// 3. 在Application中
@HiltAndroidApp
class MyApp : Application()

// 4. 在Activity中（完成！）
@AndroidEntryPoint
class UserActivity : AppCompatActivity() {
    private val viewModel: UserViewModel by viewModels()
    
    @Inject
    lateinit var repository: UserRepository
}

// 5. 在Fragment中（完成！）
@AndroidEntryPoint
class UserFragment : Fragment() {
    private val viewModel: UserViewModel by viewModels()
}

// 行数：大约30行，少70%！
```

## Hilt 预定义的 @InstallIn

```kotlin
@InstallIn(SingletonComponent::class)      // 全局单例

@InstallIn(FragmentComponent::class)       // Fragment生命周期
@InstallIn(ServiceComponent::class)        // Service生命周期
@InstallIn(BroadcastReceiverComponent::class)  // BroadcastReceiver
@InstallIn(ViewComponent::class)           // Custom View
@InstallIn(ViewWithFragmentComponent::class)   // Fragment内的View
```

## 何时选择

### 选择 **Hilt** 🟢（推荐）

- ✅ 新项目开发
- ✅ 标准Android应用
- ✅ 快速开发，不想处理复杂配置
- ✅ 团队成员DI经验不足
- ✅ 需要在多个Activity/Fragment共享数据

### 选择 **Dagger2** 🟡

- ✅ 超复杂企业级应用
- ✅ 需要极度自定义Component结构
- ✅ 维护老项目
- ✅ 对编译速度敏感的项目
- ✅ 学习/研究DI原理

## 迁移建议

```kotlin
// Dagger2项目可以逐步迁移到Hilt

// Step 1: 添加Hilt依赖
dependencies {
    implementation "com.google.dagger:hilt-android:2.48"
    kapt "com.google.dagger:hilt-compiler:2.48"
}

// Step 2: 添加@HiltAndroidApp
@HiltAndroidApp
class MyApp : Application()

// Step 3: 逐个Activity添加@AndroidEntryPoint
@AndroidEntryPoint
class MainActivity : AppCompatActivity()

// Step 4: 使用Hilt的@InstallIn替换Dagger2 Module
@Module
@InstallIn(SingletonComponent::class)
class MyModule

// Step 5: 逐步删除手动Component代码
```

## 实战建议（面试角度）

```kotlin
// 面试时需要理解的核心差异：

1. Hilt自动生成ApplicationComponent, ActivityComponent等
   Dagger2需要手动创建

2. Hilt的@InstallIn预定义Scope
   Dagger2需要自定义@Scope注解

3. Hilt自动处理ViewModel注入
   Dagger2需要写Factory类

4. Hilt支持所有Android组件自动注入
   Dagger2需要为每个组件创建subcomponent

5. 本质上：Hilt = Dagger2 + Android约定
   Hilt牺牲灵活性换取易用性
```
