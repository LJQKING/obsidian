# Activity 生命周期及源码解析（面试高级版）

Activity 是 Android 四大组件中最核心的组件之一。理解生命周期不仅要知道回调顺序，更要理解 **ActivityThread → Instrumentation → Activity** 的调用链。

---

# 一、Activity 生命周期总览

## 正常启动

```text
onCreate()
    ↓
onStart()
    ↓
onResume()
```

此时 Activity 进入前台，可与用户交互。

---

## 按 Home 键

```text
onPause()
    ↓
onStop()
```

Activity进入后台。

---

## 再次回到前台

```text
onRestart()
    ↓
onStart()
    ↓
onResume()
```

---

## 按 Back 键

```text
onPause()
    ↓
onStop()
    ↓
onDestroy()
```

Activity被销毁。

---

## 生命周期图

```text
            onCreate()
```

# 二、生命周期详解

---

## 1. onCreate()

Activity 创建时调用。

### 主要工作

```java
@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);

    setContentView(R.layout.activity_main);

    initView();
    initData();
}
```

一般用于：

- 加载布局
    
- 初始化View
    
- 初始化ViewModel
    
- 注册监听器
    

---

### 源码

```java
public class Activity {

    protected void onCreate(Bundle savedInstanceState) {

    }
}
```

真正调用位置：

```java
Instrumentation.callActivityOnCreate()
```

---

## 2. onStart()

Activity可见但不可交互。

```java
@Override
protected void onStart() {
    super.onStart();
}
```

例如：

- 注册广播
    
- 注册EventBus
    

---

## 3. onResume()

Activity进入前台。

```java
@Override
protected void onResume() {
    super.onResume();
}
```

此时：

- 获取焦点
    
- 用户可点击界面
    

常用于：

```java
camera.startPreview();
```

```java
locationManager.startLocation();
```

---

## 4. onPause()

Activity失去焦点。

```java
@Override
protected void onPause() {
    super.onPause();
}
```

特点：

- 时间必须短
    
- 下一Activity启动前必须执行完
    

常用于：

```java
video.pause();
```

```java
saveDraft();
```

---

## 5. onStop()

Activity完全不可见。

```java
@Override
protected void onStop() {
    super.onStop();
}
```

常用于：

```java
unregisterReceiver();
```

```java
releaseCamera();
```

---

## 6. onRestart()

从后台重新回到前台。

```java
@Override
protected void onRestart() {
    super.onRestart();
}
```

执行顺序：

```text
onRestart()
↓
onStart()
↓
onResume()
```

---

## 7. onDestroy()

Activity销毁。

```java
@Override
protected void onDestroy() {
    super.onDestroy();
}
```

常用于：

```java
handler.removeCallbacksAndMessages(null);

binding = null;
```

```java
presenter.detachView();
```

## 4. Activity为什么不能new？

错误：

```java

    new MainActivity();
```

Activity必须经过系统创建：

```text
ActivityThread
↓
Instrumentation
↓

↓
```

- Context为空

- 生命周期不执行

# ActivityA 跳到 B 的生命周期

这是Android面试的**必考题**。下面是完整的生命周期调用顺序：

## 🔄 完整调用序列

```
ActivityA.onPause()
    ↓
ActivityB.onCreate()
    ↓
ActivityB.onStart()
    ↓
ActivityB.onResume()
    ↓
ActivityA.onStop()
```

## 📊 可视化时间轴

```
ActivityA                        ActivityB
─────────────────────────────────────────
  正在运行
     ↓
  onPause() ← 用户看得见A
     ↓
                             onCreate()
                                  ↓
                            onStart() ← B开始显示
                                  ↓
                            onResume() ← B获得焦点，用户看得见B
     ↓
  onStop() ← A完全隐藏
```

## 🎯 关键点

|生命周期|说明|
|---|---|
|**A.onPause()**|A失去焦点但仍可见；**必须快速执行**（延迟会卡顿启动）|
|**B.onCreate()**|B创建，进行初始化操作|
|**B.onStart()**|B变为可见|
|**B.onResume()**|B获得焦点并与用户交互|
|**A.onStop()**|A完全隐藏（此时B已经onResume完成）|

## 💡 面试常见追问

### Q1: 为什么A.onPause()要先执行？

**答案**：新Activity需要等待前一个Activity释放焦点后才能获得焦点。系统设计是**串行执行**，不是并行。

### Q2: 如果A.onPause()很耗时会怎样？

**答案**：B的启动会被阻塞，导致**启动卡顿**。因此onPause()中不要做重操作（数据库操作、网络请求等应在onStop()中做）。

### Q3: 用户按返回键回到A时，生命周期？

```
ActivityB.onPause()
    ↓
ActivityA.onStart()
    ↓
ActivityA.onResume()
    ↓
ActivityB.onStop()
    ↓
ActivityB.onDestroy()
```

### Q4: 如果B是透明Activity会怎样？

```
ActivityA.onPause()          ← A失焦但可见（B透明）
    ↓
ActivityB.onCreate()
    ↓
ActivityB.onStart()
    ↓
ActivityB.onResume()
    ↓
ActivityA.onStop() ← 不会调用！因为A仍然可见
```

## 📝 代码示例

```kotlin
// ActivityA
override fun onPause() {
    super.onPause()
    Log.d("TAG", "A.onPause")
    // 保存临时数据、取消动画等（快速操作）
}

override fun onStop() {
    super.onStop()
    Log.d("TAG", "A.onStop")
    // 数据持久化、关闭数据库等（耗时操作）
}

// ActivityB
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    Log.d("TAG", "B.onCreate")
}

override fun onResume() {
    super.onResume()
    Log.d("TAG", "B.onResume")
    // 加载数据、启动动画等
}
```

**输出**：

```
A.onPause
B.onCreate
B.onStart
B.onResume
A.onStop
```

## ⚠️ 常见错误

```kotlin
// ❌ 错误：在onPause中做耗时操作
override fun onPause() {
    super.onPause()
    db.saveData()  // 阻塞新Activity启动！
}

// ✅ 正确：在onStop中做
override fun onStop() {
    super.onStop()
    db.saveData()
}
```
